# Computer-Networks-Socket-Programming

This project was developed for the **ENCS3320 – Computer Networks** course at **Birzeit University**.

## Project Overview

This project focuses on practical networking concepts using **socket programming**.

It includes two main tasks:

### Task 2 – Web Server
A simple TCP-based web server implemented using Python sockets.

Features:
- Serves HTML pages
- Supports CSS and images
- Handles English and Arabic web pages
- Supports redirects for missing image/video resources
- Returns a custom 404 error page for invalid requests

### Task 3 – UDP Trivia Game
A multiplayer trivia game implemented using UDP sockets.

Features:
- Multiple clients can join the game
- The server broadcasts trivia questions
- Clients submit answers in real time
- Scores are tracked and displayed after each round

## Technologies Used

- Python
- TCP Sockets
- UDP Sockets
- HTML
- CSS
